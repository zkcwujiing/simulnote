# 04 · 系统架构设计

## 4.1 总体架构（单页应用，无服务端）

**没有任何服务端组件。** 唯一的网络请求是首次下载静态资源与模型权重。

## 4.2 三层解耦

### 层 1：引擎层（Engine）——可替换

每个能力定义成一个接口，多个实现类。这是「渐进增强」能落地的前提。

```ts
// src/engines/types.ts

/** 所有引擎的公共能力 */
export interface Engine {
  readonly id: string;
  /** 无需用户手势即可判断当前设备是否可用 */
  probe(): Promise<EngineAvailability>;
  /** 就绪；可能触发模型下载，需在用户手势中调用 */
  init(onProgress?: (p: DownloadProgress) => void): Promise<void>;
  dispose(): Promise<void>;
}

export type EngineAvailability =
  | { status: 'ready' }                  // 立即可用
  | { status: 'downloadable'; bytes: number }  // 需下载，需用户手势
  | { status: 'downloading' }            // 正在下载
  | { status: 'unavailable'; reason: string }; // 该设备不支持

export interface DownloadProgress {
  loaded: number;  // 0..1
  label: string;
}
```

```ts
// 语音识别
export interface AsrEngine extends Engine {
  readonly streaming: boolean;    // 是否真流式（影响 UI 反馈方式）
  start(opts: AsrOptions): Promise<void>;
  pushAudio(chunk: Float32Array): void;
  stop(): Promise<void>;
  onPartial(cb: (text: string, seg: PartialSegment) => void): void;
  onFinal(cb: (seg: FinalSegment) => void): void;
}

export interface AsrOptions {
  sampleRate: 16000;
  language: 'en';                       // 本项目固定英文，砍掉 LID
  vad?: { silenceMs: number; prerollMs: number; maxSpeechMs: number };
}

export interface FinalSegment {
  id: string;
  text: string;            // 英文原文
  startMs: number;
  endMs: number;
  confidence?: number;
  refined?: boolean;       // 是否经过二次精修
}

export interface PartialSegment {
  id: string;
  text: string;
  startMs: number;
}
```

```ts
// 翻译
export interface MtEngine extends Engine {
  translate(text: string, signal?: AbortSignal): Promise<string>;
  /** 长文本流式翻译（内置 API 支持 translateStreaming） */
  translateStreaming?(text: string): AsyncIterable<string>;
}

export interface MtOptions {
  source: 'en';
  target: 'zh';
}
```

```ts
// 摘要
export interface SumEngine extends Engine {
  summarize(input: SummarizeInput): Promise<SummaryResult>;
}

export interface SummarizeInput {
  segments: FinalSegment[];      // 精修后的完整转写
  translations: string[];        // 已有的中文译文（可直接复用，省一次翻译）
  locale: 'zh-CN';
  maxPoints?: number;
}

export interface SummaryResult {
  engineId: string;
  title: string;                 // 一句话主题
  keyPoints: string[];           // 中文要点
  numbers: ExtractedFact[];      // 关键数字（从英文原文抽取，不经翻译）
  decisions: string[];           // 结论 / 决议
  actions: string[];             // 待办
  tldr: string;                  // 三行以内速览
}

export interface ExtractedFact {
  raw: string;        // 英文原文里的原始表述，如 "about 12 percent"
  zh: string;         // 中文参考译法
  context: string;    // 所在句
}
```

### 层 2：编排层（Orchestrator）——管线

```ts
// src/pipeline/translatorPipeline.ts

export class TranslatorPipeline {
  constructor(registry: EngineRegistry);
  /** 探测所有引擎，选出每环节实际使用的一档 */
  plan(): Promise<PipelinePlan>;
  /** 用户手势中调用：初始化选中的引擎（可能触发下载） */
  prepare(plan: PipelinePlan, onProgress: ProgressFn): Promise<void>;
  /** 开始一次同传会话 */
  start(opts: SessionOptions): Promise<void>;
  /** 停止并触发总结 */
  stopAndSummarize(): Promise<SummaryResult>;
  /** 会话事件流 */
  events: EventEmitter<PipelineEvent>;
}

export type PipelineEvent =
  | { type: 'partial'; seg: PartialSegment }
  | { type: 'final'; seg: FinalSegment }
  | { type: 'translation'; segId: string; zh: string; done: boolean }
  | { type: 'refined'; segId: string; seg: FinalSegment }
  | { type: 'summary-chunk'; text: string }        // 流式摘要
  | { type: 'summary-done'; result: SummaryResult }
  | { type: 'engine-degraded'; stage: Stage; from: string; to: string; reason: string }
  | { type: 'error'; stage: Stage; error: Error };
```

**二次精修（借鉴 hayamimi 的 two-pass refine）**：

```
静音 2s 后 → 取最近 N 个 final 段落组成一个 group
          → 用更高质量的配置重解码该 group 的原始音频
          → 得到 refined 段落，替换掉 live 结果
          → 精修结果同时喂给摘要模块
```

一期若 L0（Web Speech）不支持重解码，则退化为「只对已定稿文本做一次翻译校正」，精修作为 P2 功能。

### 层 3：表现层（View）

| 区域 | 内容 | 状态来源 |
|---|---|---|
| 顶部控制条 | 开始/停止按钮、引擎档位指示、隐私模式开关、设置 | `engineStatus` |
| 主区（双语流） | 左侧英文原文（partial 为灰色斜体）、右侧中文译文 | `segments` + `translations` |
| 侧栏（纪要） | 实时累积的要点、关键数字、待办 | `summary` |
| 底部状态 | 延迟、音频电平、模型下载进度、丢句告警 | `stats` |
| 导出 | Markdown / TXT / SRT | `segments` |

**渲染性能要求**：10 分钟讲话会产生数百条段落。必须用**虚拟列表**（`@tanstack/react-virtual`）并保证自动滚动不与用户手动翻阅打架（用户上滚即暂停自动滚动）。

## 4.3 一次完整会话的时序

```
用户点击「开始」
   │
   ├─▶ probe() 全部引擎 ──▶ plan() 得到档位 ──▶ (需下载则弹进度条) ──▶ prepare()
   │
   ├─▶ getUserMedia ──▶ AudioWorklet(重采样到 16kHz mono f32)
   │        │
   │        ├─▶ VAD：检测到语音开始 ──▶ 带 0.8s 预滚的音频推入 ASR
   │        │
   │        └─▶ VAD：静音 0.35s ──▶ 本句结束
   │
   ├─▶ ASR: onPartial ──▶ 更新灰色草稿行
   │   ASR: onFinal   ──▶ 落定英文行 ──▶ 触发 MT.translate()
   │                                   └─▶ 译文流式追加到右侧
   │
   ├─▶ [静音 2s] ──▶ 精修 group ──▶ 替换 live 结果 ──▶ 摘要缓冲区增量更新
   │
   └─▶ 用户点击「停止」
           │
           ├─▶ 等待所有 in-flight 翻译与精修落地
           ├─▶ 数字/专有名词抽取（从英文原文，不经翻译）
           ├─▶ SUM.summarize(全部 refined segments)
           ├─▶ 流式渲染摘要 ──▶ 完成
           └─▶ 写入 IndexedDB，展示导出按钮
```

## 4.4 摘要模块的详细设计（差异化核心）

### 三段式提示词策略（避免长文超上下文）

| 阶段 | 输入 | 输出 |
|---|---|---|
| Chunk 摘要 | 每 ~40 段英文原文 + 已有中文译文 | 该段的中文要点列表 |
| 全局归并 | 所有 chunk 要点 | 去重、合并、按主题聚类的要点 |
| 结构化成稿 | 归并后的要点 + 抽出的数字 | 主题 / 要点 / 数字 / 结论 / 待办 / TLDR |

### 输出模板（固定结构，保证每次都有东西）

```markdown
# {一句话主题}

## 速览
{三行以内 TLDR}

## 要点
1. …
2. …

## 关键数字与事实
| 原文表述 | 中文 | 出处 |
|---|---|---|

## 结论与待办
- 结论：…
- 待办：…
```

### 降级路径（永不失败）

| 档位 | 引擎 | 失败时 |
|---|---|---|
| L1 | WebLLM Qwen2.5-1.5B-Instruct q4f16 | → L2 |
| L2 | transformers.js Qwen2.5-0.5B-Instruct | → L3 |
| L3 | **TextRank 抽取式（纯 JS）** | 不可能失败；输出「关键句列表」而非生成式要点 |
| L4 | 若文本为空 | 输出「本次未识别到有效语音」+ 保留原始转写 |

## 4.5 错误与降级策略

| 场景 | 行为 |
|---|---|
| 用户拒绝麦克风权限 | 明确提示 + 提供「上传音频文件」替代入口 |
| 某引擎 `unavailable` | 自动降到下一档，顶部状态条以轻提示告知（不弹窗、不阻断） |
| 降级到 L3 摘要 | 界面注明「本次为快速模式纪要，未使用 AI 生成」 |
| `Translator` 需下载语言包 | 出现「启用增强翻译」按钮，点击后显示进度条 |
| 模型下载失败/中断 | 保留已下部分，提供重试；不阻断 L0 路线（Web Speech 无需下载） |
| 检测到「转写长度远短于语音时长」 | 弹出丢句告警（借 hayamimi 的检测思路） |
| WebGPU 不可用 | 静默切 WASM，仅状态条体现 |
| 页面内存告警 | LRU 卸载非活跃模型（借 hayamimi 的 `--max-resident` 思路） |

## 4.6 隐私设计

| 项 | 默认 | 说明 |
|---|---|---|
| 音频上传 | **否** | 只有选择「快速模式」且用 Web Speech 时才可能经第三方；界面明确标注 |
| 文本上传 | **否** | 翻译与摘要均在本地 |
| 分析埋点 | **无** | 不引入任何分析 SDK |
| 数据存储 | 用户浏览器 IndexedDB | 不传云 |
| BYOK 密钥 | 若用户填写，仅存 localStorage | 界面明确告知「只存在你自己的浏览器里」 |
| 未知键 | 全部自实现，无第三方追踪 | — |
